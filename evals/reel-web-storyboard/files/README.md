# NoteDesk

A focused notes app for writers who want a clean desk.

## What you see

Open NoteDesk and you get a three-pane desk: folders on the left, the editor in the middle, and a preview on the right. The navbar shows the NoteDesk mark from `public/logo.svg`.

## Try it

Visit https://notedesk.example after signup.

## Develop

```bash
npm install
npm run dev
```
